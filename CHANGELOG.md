# Changelog

Measured numbers are not stored here. They live in `METRICS.md`, which is generated by
`python scripts/generate_metrics.py` from the committed evaluation scripts, and CI fails if it
drifts. Parameters such as the 6,000-token payload cap are code constants, not measurements.

## 1.0.1 — 2026-11-07

- Fix project URLs in package metadata.

## 1.0.0 — 2026-11-06

### Added

- Exhaustive call-site ground truth: Jedi for Python (requests, click, flask; held-out
  werkzeug) and the TypeScript compiler API for TS/JS (zod, nest, bulletproof-react,
  node-fetch, express; held-out zustand, moment). Per-repo, per-group and per-form
  precision/recall with 95% Wilson intervals, wired into `METRICS.md`.
- `verify/` evidence suite: 5k/20k/50k scale, incremental differential after random edits,
  watcher end-to-end, network-blocked queries, MCP through the built wheel, robustness
  inputs, dogfood slices.
- Slice size comparison (`benchmarks/size_compare.py`) and README worked examples generated
  from real engine output.
- CI matrix: ubuntu/macos/windows with Python 3.12 and 3.13, offline metrics/README drift
  check, wheel build and clean-venv Python/TS smoke test.
- Windows `LOCALAPPDATA` cache path and simulated Windows/macOS/Linux path tests, plus
  case-insensitive path and CRLF coverage.

### Fixed

- TypeScript/JavaScript: default imports; emitted specifier mapping (`.js` to `.ts`/`.tsx`,
  `.mjs`/`.cjs`/`.jsx`); specifiers whose basename contains a dot; `super.m()` against base
  classes; property-assigned function bodies; bare calls binding to property methods.
- Python: incremental module reconciliation, call+type relations on one pair, nested
  `TYPE_CHECKING`/try imports, module-scope symbols, getter/setter and overload spans,
  `super()` and constructed receivers.
- Removed stale test-selection references from README, CHANGELOG, CLI help and benchmarks.

### Changed

- `impact_of_diff` returns changed and impacted symbols only; no test selection.
- `METRICS.md` and `README.md` are generated; `scripts/generate_metrics.py --check` verifies
  both offline.

### Removed

- `benchmarks/stage_b/run.py`, `benchmarks/fault/run_click.py` and the Stage B METRICS
  section.

### Notes

- The first run downloads the tree-sitter grammars, so it needs internet once; after that
  indexing and queries run offline. No code leaves the machine.

### Measured

See `METRICS.md`.

## 0.4.0 — 2026-10-31

### Added

- `impact_of_diff(base, head | diff)`: parses a unified diff, maps changed lines to symbols,
  walks upstream call edges, and returns changed and impacted symbols by hop.
  Verified on real git commits.
- Slice context: each region carries `# class X:` and the referenced `# import:` lines
  without repeating the sliced code.
- TypeScript: `tsconfig` `baseUrl`/`paths`, `export *` barrel re-exports, and verified
  `.tsx`/`.js` grammar loading.
- `benchmarks/agent_eval/`: dry-run harness that measures tool payload tokens per task and
  marks resolve rate UNMEASURED. No model adapter is shipped.

### Measured

See `METRICS.md`.

## 0.3.0 — 2026-10-31

### Changed (breaking)

- Removed the 0.50 name-only edge tier; unresolved and ambiguous calls now produce no edge and
  are tracked in a reverse index for incremental relinking.
- `get_ast_call_slice` caps the exact JSON payload at 6,000 tokens by default, applies per-hop
  fan-out caps (10) and a total cap (40), and treats symbols with degree >= 150 as hubs.
- Metadata requires `include_metadata=True`; the default payload is `compiled_context` plus
  token metrics and diagnostics.
- Ambiguous queries return `code: "ambiguous_symbol"` with all candidates.
- The SQLite index moved from the repository into the OS cache directory.
- `explain_edge` exposes per-edge provenance (`resolution`, `line`, `receiver`, `name`).

### Added

- Self-recursion is kept as a self-edge and reported separately.
- `POLYGLOT_AST_ALLOWED_ROOTS` allowlist; escaping symlinks, binary files and oversized files
  are skipped and reported.
- Differential test: incremental graph must equal a from-scratch rebuild after random edits.

### Fixed

- Symlinked source files outside the repository crashed indexing.
- Read-only checkouts failed to open the cache database.
- Class-level TS static factories made the class look self-recursive.
- Bare calls such as `open(...)` inside a class bound to a same-named method.
- Nested/local classes and functions now resolve within their lexical scope.

See `METRICS.md`.
