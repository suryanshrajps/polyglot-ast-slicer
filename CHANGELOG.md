# Changelog

All notable changes are recorded here. Numbers are generated by the committed scripts in
`benchmarks/` and by the eval harness described in each entry.

## 0.3.0 — 2026-10-31

### Changed (breaking)

- **No name-only edges.** The 0.50 "unique repo-wide name" tier is removed. Unresolved and
  ambiguous calls produce no edge and are tracked in a reverse index for incremental relinking.
  Measured on 100 random call edges per repo (Jedi 0.20.1, canonicalized re-exports):
  `psf/requests` 99/100 supported (99%), `pallets/click` 100/100 (100%).
- **Payloads are budgeted and slim.** `get_ast_call_slice` caps the exact JSON payload at
  6,000 tokens by default, applies per-hop fan-out caps (10) and a total cap (40), and treats
  symbols with degree >= 150 as hubs. Metadata requires `include_metadata=True`.
  `token_metrics.payload_tokens` is computed on the returned JSON.
- **Ambiguity is refused, not guessed.** `get`-style queries return `code: "ambiguous_symbol"`
  with all candidates; callers must use `<path>::<qualified_name>`.
- **Cache location.** The SQLite index moved from `<repo>/.ast_slicer_cache.db` to the OS cache
  directory, keyed by a hash of the repository path. Read-only checkouts now index normally.
- **`explain_edge` returns provenance.** Every call edge stores `resolution`, `line`,
  `receiver` and `name`; the new tool exposes them.

### Added

- Self-recursion is kept as a self-edge and reported separately under `self_recursive`.
- `POLYGLOT_AST_ALLOWED_ROOTS` allowlist; symlinks escaping the repository are skipped and
  reported; binary and oversized files are reported in `skipped_files`.
- Hypothesis-style differential test: after each random add/remove/rename edit, the
  incremental graph must equal a from-scratch rebuild.

### Fixed

- Symlinked source files outside the repository crashed indexing with `ValueError`.
- Read-only checkouts failed with `OperationalError: unable to open database file`.
- Class-level TS static factories (`static create = () => new Foo()`) made the class look
  self-recursive; those bodies now belong to the extracted member symbol.
- Bare calls such as `open(...)` inside a class no longer bind to a same-named method.
- Nested/local classes and functions now resolve within their lexical scope (0.90).

### Measured

- `requests`: 782 edges, 191 ms cold, 49 ms warm, 99% edge precision on 100 sampled edges.
- `click`: 2,283 edges, 436 ms cold, 126 ms warm, 100% edge precision on 100 sampled edges.
- `zod` v3.23.8: 1,124 edges, 296 ms cold, 68 ms warm; 5 JavaScript files skipped because the
  grammar could not be downloaded in this environment.
- Hub query `src/click/decorators.py::command`: 5,493 payload tokens, 321 upstream entries
  omitted (v0.2.0: 89,698 tokens).
