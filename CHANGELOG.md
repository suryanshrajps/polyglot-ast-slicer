# Changelog

Measured numbers are not stored here. They live in `METRICS.md`, which is generated by
`python scripts/generate_metrics.py` from the committed evaluation scripts, and CI fails if it
drifts. Parameters such as the 6,000-token payload cap are code constants, not measurements.

## 0.4.0 — 2026-10-31

### Added

- `impact_of_diff(base, head | diff)`: parses a unified diff, maps changed lines to symbols,
  walks upstream call edges, and returns changed symbols, impacted symbols by hop, and
  impacted tests. Verified on real git commits.
- Slice context: each region carries `# class X:` and the referenced `# import:` lines
  without repeating the sliced code.
- TypeScript: `tsconfig` `baseUrl`/`paths`, `export *` barrel re-exports, and verified
  `.tsx`/`.js` grammar loading.
- `benchmarks/agent_eval/`: dry-run harness that measures tool payload tokens per task and
  marks resolve rate UNMEASURED. No model adapter is shipped.

### Measured

See `METRICS.md`.

## 0.3.0 — 2026-10-31

### Changed (breaking)

- Removed the 0.50 name-only edge tier; unresolved and ambiguous calls now produce no edge and
  are tracked in a reverse index for incremental relinking.
- `get_ast_call_slice` caps the exact JSON payload at 6,000 tokens by default, applies per-hop
  fan-out caps (10) and a total cap (40), and treats symbols with degree >= 150 as hubs.
- Metadata requires `include_metadata=True`; the default payload is `compiled_context` plus
  token metrics and diagnostics.
- Ambiguous queries return `code: "ambiguous_symbol"` with all candidates.
- The SQLite index moved from the repository into the OS cache directory.
- `explain_edge` exposes per-edge provenance (`resolution`, `line`, `receiver`, `name`).

### Added

- Self-recursion is kept as a self-edge and reported separately.
- `POLYGLOT_AST_ALLOWED_ROOTS` allowlist; escaping symlinks, binary files and oversized files
  are skipped and reported.
- Differential test: incremental graph must equal a from-scratch rebuild after random edits.

### Fixed

- Symlinked source files outside the repository crashed indexing.
- Read-only checkouts failed to open the cache database.
- Class-level TS static factories made the class look self-recursive.
- Bare calls such as `open(...)` inside a class bound to a same-named method.
- Nested/local classes and functions now resolve within their lexical scope.
